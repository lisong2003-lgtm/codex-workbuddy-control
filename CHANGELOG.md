# Changelog

## 0.1.3 - 2026-11-24

- Replaced the icon with a deep-blue-to-bright-blue gradient rounded-square
  icon with a white 3D document-arrow-check symbol, matching the same visual
  series as the published `cad-suite` SkillHub icon (v0.4.6). Removed the
  generator watermark from the 1024 source before producing 512/256 assets.
- Republished all three platforms at 0.1.3 so the SkillHub display icon uses
  the same series.

## 0.1.2 - 2026-11-24

- Attached the platform-style blue icon as the SkillHub display icon and
  republished all three platforms at the same version.

## 0.1.1 - 2026-11-24

- Replaced the blueprint icons with platform-style blue rounded-square icons at
  512x512 and 256x256 (ocean blue background, white document-arrow-check mark).
- Bumped version for a three-platform republish of the icon update.

## 0.1.0 - 2026-11-24

- Added the standard-library task bus with `init`, `status`, `dispatch`,
  `verify`, `claim`, and `complete`.
- Added `WB-*`, `WBV-*`, and `WBC-*` workflows.
- Added SHA-256 manifests, portable-command warnings, shared ledger updates,
  and monthly reviews.
- Added reusable task, receipt, verification-request, and verification-result
  templates.
- Added direct-start prompts, staged prompts, setup notes, and troubleshooting.
- Added isolated regression tests and package validation hooks.
- Added text-free, gradient-free blueprint icons at 512×512 and 256×256, plus
  agent and manifest icon references.
